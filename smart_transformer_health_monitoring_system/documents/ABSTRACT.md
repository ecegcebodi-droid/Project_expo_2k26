Smart Transformer Health Monitoring and Fault Detection System Using ESP32 is an IoT-based system designed for continuous monitoring of transformer operating conditions. The system uses an ESP32 controller to collect data from sensors such as DS18B20 temperature sensor, DHT11 humidity sensor, smoke sensor, water/level sensor, and sound sensor. The collected sensor data is processed and compared with predefined threshold values to classify the transformer condition as NORMAL, WARNING, or DANGER.
The system provides local indication through a 16×2 I2C LCD, green/yellow/red LEDs, and a buzzer. At the same time, the monitored parameters are transmitted to the Blynk IoT platform through Wi-Fi, enabling real-time remote monitoring on a mobile device. This helps identify abnormal conditions at an early stage and can support preventive maintenance.
In the present prototype, voltage and current values are project-level approximate values derived from temperature for demonstration. For practical transformer installation, properly rated and electrically isolated voltage and current sensors such as VT/isolated voltage transducers and CT/current transducers should be used. The proposed system can be further enhanced with DGA, oil-moisture sensing, vibration/partial-discharge monitoring, data logging, SCADA/cloud integration, and AI-based predictive maintenance.
